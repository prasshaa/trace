# Trace pathway review pack (evaluation fixtures)

These are constructed test careers, not real people, and the evidence is from constructed test profiles. Please judge each pathway as you would for a real person with this background.

Pathways are listed in an arbitrary order. Trace's own ordering and labels are deliberately hidden.

For each pathway answer, in your own reviewer file:
1. Is it plausible given this person's background? 2. Is it relevant to their experience and target? 3. Are the intermediate roles sensible? 4. Is it meaningfully different from the alternatives? 5. Does the supporting evidence justify presenting it?

For each scenario: 6. Which pathway would you prioritise? 7. Why? 8. What information is missing to make a better recommendation?

Relevance rubric: not_relevant, weakly_relevant, reasonably_relevant, strongly_relevant, cannot_assess. Explain any judgment in the notes column.
